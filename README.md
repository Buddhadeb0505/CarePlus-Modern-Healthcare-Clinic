# CarePlus Modern Healthcare Clinic — Website

A responsive, front-end demo website built with separate HTML, CSS and JavaScript files.

## Project files
- `index.html` — page structure, SEO metadata and structured data
- `styles.css` — responsive layout, typography, colors and components
- `script.js` — mobile navigation, date validation, WhatsApp links and form interaction

## Run locally
1. Download and extract the ZIP file.
2. Open the `careplus-modern-healthcare-clinic` folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

No build tools or package installation are required.

## Important setup before publishing
This is a front-end demonstration, not a live clinic booking system. Before launch:
1. Replace the example phone number in `index.html` and `WHATSAPP_NUMBER` in `script.js` with the clinic's verified number (digits only, including country code).
2. Add the full verified clinic address, opening hours and a real Google Maps location.
3. Replace sample doctor names, photos, qualifications, specialties and availability with approved details.
4. Replace sample testimonials with genuine testimonials published with patient consent.
5. Verify every department/service and have all health articles reviewed by a qualified clinician.
6. Add a real privacy policy and appropriate consent/data-handling process.
7. Connect the enquiry form to a secure backend, CRM or approved booking provider if you need submissions stored. Currently, the form opens WhatsApp and does not save data.
8. Replace external demo images with properly licensed clinic photography where possible.

## SEO notes
The page includes a descriptive title, meta description, heading hierarchy, semantic sections, image alt text, Open Graph metadata and starter MedicalClinic JSON-LD structured data. Update structured data with the clinic's actual address, phone, URL, hours and verified specialties. Submit the live sitemap through Google Search Console after deployment.
